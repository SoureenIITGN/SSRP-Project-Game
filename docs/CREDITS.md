# Credits and asset sources

Only use assets we are allowed to use. Every file that did not come from our own code must be
listed here, with its source and licence.

## Sound effects (`Assets/Audio/SFX/`)

All of them were generated procedurally by `tools/generate_sfx.py`, our own code that uses only
the Python standard library. No third-party audio is included. Licence: same as this repository.

| File | Used for | Recipe |
|---|---|---|
| `paddle_hit.wav` | Ball hits a paddle | 520 to 440 Hz square blip with a click of filtered noise |
| `wall_hit.wav` | Ball hits a wall | 300 to 260 Hz triangle blip |
| `tile_hit.wav` | Ball hits a tile | 880 to 700 Hz square blip with noise |
| `tile_break.wav` | Tile destroyed | Filtered noise burst with a falling square sweep |
| `goal.wav` | Goal scored | C-E-G-C square arpeggio |
| `parry.wav` | Any parry press (quiet) | Rising two-voice sine shimmer |
| `parry_success.wav` | Successful parry | Bass thump, noise crack, inharmonic metallic ring (5 partials, detuned pairs) + small-room reverb |
| `countdown_tick.wav` | 3, 2, 1 | 660 Hz sine |
| `countdown_go.wav` | GO! | 990 Hz sine |
| `match_over.wav` | Results screen | G-E-C-C triangle phrase |

## Sprites (`Assets/Art/Sprites/`)

All generated by `tools/generate_art.py` (simple shapes drawn with Pillow), so they are our own work.

## Fonts

The UI uses Unity's built-in `LegacyRuntime.ttf`, which ships with the editor.

## Adding a third-party asset

Add a row with the file, the author, the source URL and the licence (for example CC0 or CC-BY 4.0
with the attribution text). Assets without a clear licence are not allowed.
